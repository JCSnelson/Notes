Roles:
Peripheral Management - managing drivers and interrupts for various I/O devices.
Interrupt Service Routine - Makes sure the higher priority interrupts get handled appropriately
Memory Management - Segmentation (dynamic sized segments) vs paging (fixed size) and managing the page table as well as virtual vs actual addresses in main memory.
Storage Management - Manage files and where they are stored as well as how they are stored and loading pages/segments correctly into main memory when needed.
Security - Making sure no hackers go hacky
Processor Scheduling - When do processes get time etc. (multi level feedback queues)

Types of OS:
Distributed -  Separate computers joined through network connections and managed by this type of OS to utilize all resources for more intensive tasks.
Embedded - lightweight, made for specific tasks and hardware to be more reliable.
Multitasking - just like switch fast between tasks to give the illusion many are running at once.
Real Time -  Perform tasks in a consistent time frame in high risk scenarios, not as flexible. e.g. autopilot.

System Software:
BIOS - basic input output system, used for setting up the computer and some drivers
Drivers - used to define the rules for communicating with certain devices within the computer
Virtual Machines - Used to emulate any kind of hardware in order to test software, contain programs and emulate different operating systems
